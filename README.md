# Hi, I'm Priyan 👋

**QA Engineer** · Manual, API & Test Automation · Playwright (TypeScript) · Chennai, India

I test enterprise web applications and REST APIs. I'm currently a freelance QA engineer on Procter & Gamble's **CRS 2.0** consumer-data platform, where I own testing across seven modules, including Traits, Consents, Events and Marketing Programs, in an Agile team.

Before that, I spent two years at **Voltas (TATA)** as Assistant Manager, Production & Operations. Alongside the operations role, I tested SAP material-management flows during a legacy-to-new migration and did UAT on the company's Employee Self-Service portal. That's where I moved into QA.

---

### 🔍 What I do

- **Test design & execution:** positive, negative and edge-case test cases; functional, regression, smoke, sanity, exploratory and UAT testing
- **API testing:** REST validation in Postman (payloads, status codes, auth, UI-vs-API consistency); API integration suites in CodeceptJS
- **Test automation:** Playwright with TypeScript, Page Object Model, custom fixtures, data-driven and parallel runs, cross-browser (Chromium, Firefox, WebKit), CI with GitHub Actions
- **Test & defect management:** Zephyr test cycles and bulk test-case imports; Jira defect lifecycle from reproduction to retest and closure

### 📊 Recent work

- **P&G CRS 2.0:** 343 test cases designed and executed in Zephyr across three test cycles; 100+ defects tracked in Jira; ran and maintained the team's API integration suite across 11 modules
- **Voltas (TATA):** SAP regression testing during migration; 497 UAT test cases for the ESS portal and company website
